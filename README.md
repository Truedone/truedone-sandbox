# truedone-sandbox

Demonstration pull requests for [truedone](https://github.com/mgillr/truedone). Each pull request is one change to
main that truedone must give one verdict; truedone's docs/demo/expected.json lists them.

Three small projects, one per runner truedone version 1 supports: node-test/ (node --test), vitest/ (vitest) and
python/ (pytest). Some functions here are wrong on purpose: the pull requests fix them.

The preview acceptance walk opened this pull request on 2026-10-19T09:35:03Z to check the production App.
